ПАДЕЖИ 4 КЛАСС — ПОДКЛЮЧЕНИЕ GOOGLE ТАБЛИЦЫ

Google Таблица уже создана:
https://docs.google.com/spreadsheets/d/1hJ_1cPte4hH5lzT14JpLfmJ36XXWtpxw3bvwOCj3Q-M/edit

В ней есть листы:
1) Результаты — одно прохождение блока = одна строка.
2) Ответы — одно задание = одна строка.
3) Аналитика — сводки по ученикам, блокам и частым ошибкам.

КАК ПОДКЛЮЧИТЬ APPS SCRIPT

1. Откройте созданную Google Таблицу.
2. Меню: Расширения → Apps Script.
3. Удалите стандартный код из редактора.
4. Скопируйте весь текст из файла Code.gs и вставьте в редактор.
5. Сохраните проект.
6. В редакторе Apps Script один раз запустите функцию setupSheets.
   Google попросит разрешения — подтвердите доступ к вашей таблице.
7. Нажмите Развернуть → Новое развертывание.
8. Тип: Веб-приложение.
9. Выполнять от имени: Я.
10. Кто имеет доступ: Все (если ученики не должны входить в Google-аккаунт).
11. Нажмите Развернуть и скопируйте URL веб-приложения. Он заканчивается на /exec.

КАК ПОДКЛЮЧИТЬ HTML-ТРЕНАЖЁР

1. Откройте файл padezhi_4klass_trenazher.html в текстовом редакторе.
2. Найдите строку:
   GAS_URL: 'PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE',
3. Вместо PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE вставьте URL веб-приложения Apps Script (с /exec).
4. Сохраните файл.
5. Разместите HTML на GitHub Pages / Netlify или другом HTTPS-хостинге.

Важно: если открыть HTML просто как локальный файл, сам тренажёр работает, но отправка в Google Таблицу надёжнее после публикации на HTTPS-сайте.

КАК РАБОТАЕТ СБОР ДАННЫХ

— Ученик вводит только имя.
— После завершения блока HTML формирует session_id и отправляет результат.
— Apps Script проверяет session_id, поэтому дубль одной и той же отправки не добавляется.
— Повторное прохождение того же блока получает номер Попытка 2, 3 и т. д.
— Если интернет пропал, результат сохраняется в браузере и повторно отправляется позже.
— В блоке В. п. ↔ Р. п. отдельно считается количество вызовов лисы.

АНАЛИТИКА

Лист «Аналитика» обновляется автоматически после каждого принятого результата.
Также его можно обновить вручную через меню таблицы:
Тренажёр → Обновить аналитику.

ЧТО ПОКАЗЫВАЕТ АНАЛИТИКА

— средний итог по ученику;
— процент правильных ответов с первой попытки;
— количество ошибок;
— использование подсказок;
— количество вызовов лисы;
— среднее время выполнения;
— показатели по каждому блоку;
— задания, в которых чаще всего ошибаются.

БЕЗОПАСНОСТЬ

Тренажёр передаёт только учебные данные: имя, ответы, время, подсказки и результаты. Фамилия, школа, телефон и другие персональные данные не запрашиваются.

Файлы:
— padezhi_4klass_trenazher.html — готовый тренажёр;
— Code.gs — код Google Apps Script;
— README_подключение_тренажера.txt — эта инструкция.
